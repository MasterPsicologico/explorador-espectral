Limitaciones conocidas

Xiaomi declara acelerómetro, giroscopio, brújula/campo magnético, sensor de luz ambiental, proximidad y emisor IR. El emisor IR sirve para controlar aparatos: no es receptor IR. El fabricante no declara cámara térmica ni barómetro. El acceso web a sensores depende del navegador. Esta aplicación registra señales físicas; no detecta fantasmas ni dimensiones.
